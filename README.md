# Glynn Website

Clone of point-intl.com for development and iteration.

## Pages
- `index.html` — Home with full-screen image stack and brand statement
- `brands.html` — Brand portfolio grid

## Local preview
Open `index.html` directly in a browser, or serve with:
```
python3 -m http.server 8765
```
Then visit http://127.0.0.1:8765/
